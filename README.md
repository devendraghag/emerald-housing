# Emerald Housing

A Java 21 and Spring Boot housing society management project. It brings together backend services, a Vue frontend, PostgreSQL, Redis, Kafka, and Kubernetes deployment resources to demonstrate practical application and distributed-systems patterns.

## Start here

Open **[index.html](index.html)** in a browser. The guide explains the system, its architecture and roadmap, Kubernetes configuration, API reference, and operational topics.

The frontend lives in the sibling [emerald-housing-frontend](https://github.com/devendraghag/emerald-housing-frontend) repository.

## Repository map

- `services/` — Spring Boot application services
- `infrastructure/` — shared infrastructure and API gateway resources
- `kubernetes/` — deployment, service, networking, and autoscaling manifests
- `postman/` and `contracts/` — API examples and contracts
- `docs/kafka-operations.md` — Kafka dead-letter handling and monitoring notes
- `index.html` — interactive project and operations guide

## Technology

Java 21 · Spring Boot · PostgreSQL · Redis · Kafka · Docker Compose · Kubernetes
